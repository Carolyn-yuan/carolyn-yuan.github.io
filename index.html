Research Experiences

An Autonomous Music Performer Based on ArmPi FPV Vision Robotic Arm
Graduate Thesis Student, Supervised by Prof. Chunhong Zheng, Xidian University
11/2025 – 05/2026
  • Developed a lightweight embedded music performance system on Raspberry Pi 4B and ArmPi 6-DOF robot arm, enabling real-time printed music score recognition using OpenCV and Tesseract.
  • Built a pipeline integrating image acquisition, printed music score recognition, structured data generation, and robot arm trajectory planning for piano key mapping.
  • Implemented non-linear physical calibration, reducing positioning error between arm arc motion and piano key layout from 5.0mm to ≤1.2mm.
  • Designed a Context-aware fusion strategy for visual matching and melodic consistency check, improving recognition accuracy to 95.7% in noisy conditions.
  • Achieved <45ms frame latency in a lightweight deployment.
Reconfigurable Computing Architecture
Research Student, Supervised by Prof. Christian Claudel, University of Texas at Austin
11/2025 – Present
  • Implemented an FPGA-based neural network accelerator supporting training and inference.
  • Developed a floating-point Python reference model to validate backpropagation-based training behavior.
  • Completed VHDL design and system integration, verifying hardware functionality using TestBench.
  • Expanded sample size to 100, achieving convergence within 1249 iterations based on standard ReLU and Leaky ReLU, with a final ISE (integrated squared error) of 0.013.
  • Compared Python floating-point and VHDL models to analyze hardware-induced convergence degradation.
A Pipeline Defect Detection and Repair Solution Recommendation System by YOLOv8
Research Assistant, Supervised by Prof. Peng Yan, Shaanxi A&F Technology University
11/2025 – 03/2026
  • Trained a YOLOv8 model using a dataset reconstructed via an OpenCV pipeline, achieving 87.5% mAP across 7 defect types.
  • Developed a rule-based mapping engine, automatically matching real-time object detection outputs with a standardized pipeline repair database.
  • Built a Tkinter-based desktop App integrating real-time inference window, Matplotlib statistical visualizations, TTS audio alerts, and PDF report export.
An RGB-Thermal Fusion YOLO for All-Weather Object Detection
Research Assistant
03/2026 – 06/2026
  • Built a multimodal data pipeline to process and align 5,142 RGB-Thermal image pairs, and implemented a dual-branch backbone to fuse spatial and thermal features.
  • Co-designed a Context-Guided Task-Aligned Head (CGTA Head) to resolve feature conflicts between object classification and bounding box regression.
  • Evaluated framework on the FLIR dataset, achieving 75.2% mAP50 at 92.9 FPS while reducing model parameters by 8.2% to 4.5M.
